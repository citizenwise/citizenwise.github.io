In 3 Schritten starten

  1. Öffnen Sie die App. Wählen Sie Ihr Bundesland.
  2. Beantworten Sie die ersten Fragen. Sagen Sie der App dann, wann Ihr Test ist.
  3. Üben Sie jeden Tag ein paar Minuten. Tippen Sie auf der Startseite auf den großen Knopf. Er zeigt immer Ihren nächsten Schritt.

Der erste Start

Sie brauchen kein Konto. Die App fragt Sie ein paar Dinge, Schritt für Schritt.

  1. Ein kurzer Hinweis. Citizenwise ist eine Lern-App. Sie ist nicht vom BAMF. Tippen Sie auf „Los geht’s“.
  2. Ihr Bundesland. Im Test bekommen Sie 3 Fragen zu Ihrem Bundesland. Tippen Sie auf „Bundesland wählen“. Sie können in der Liste suchen, mit dem Namen oder dem Kürzel. Später wählen? Tippen Sie auf „Vorerst überspringen“. Sie können es dann in den Einstellungen wählen.
  3. Die ersten Fragen. So sehen Sie, wo Sie anfangen. Ein niedriges Ergebnis ist kein Problem.
  4. „Wann ist Ihr Test?“ Wählen Sie „In 1–2 Monaten“, „Datum eingeben“ oder „Weiß ich noch nicht“. Mit einem Datum tippen Sie auf „Meinen Plan starten“. Ohne Datum tippen Sie auf „Jetzt üben“. Darunter öffnet „So funktioniert die App“ diese Anleitung.

Welchen Test übt die App?

Den Einbürgerungstest. Er heißt auch „Leben in Deutschland“. Es ist derselbe Test.

  • Die App hat alle 300 Fragen für ganz Deutschland und die 10 Fragen für Ihr Bundesland.
  • Im Test bekommen Sie 33 Fragen: 30 allgemeine Fragen und 3 zu Ihrem Bundesland.
  • Sie haben 60 Minuten. Mit 17 richtigen Antworten haben Sie bestanden.

Start

Die Startseite zeigt, wie weit Sie sind und was Sie als Nächstes tun.

  • Oben: eine Begrüßung und die Tage bis zum Test, zum Beispiel „Test in 30 Tagen“. Oben rechts öffnet das Zahnrad die Einstellungen.
  • „Lernstand“: Der Ring zeigt eine Prozentzahl. Die Hälfte kommt aus den Fragen, die Sie gelernt haben. Die andere Hälfte kommt aus Ihren letzten 5 Probetests. Das ist nur ein Hinweis, keine Garantie für das Ergebnis im Test. Tippen Sie auf „Lernstand“, dann sehen Sie mehr.
  • Der große Knopf: Ihr nächster Schritt. Er ändert sich. Zum Beispiel: „Plan für heute“, „12 Fragen wiederholen“, „Jetzt Probetest starten“ oder „Weiter: (ein Thema)“.
  • „Ziel heute“: wie viele Fragen Sie heute geübt haben. Für jeden Tag der Woche mit Lernen gibt es einen Punkt.
  • Unten: schnelle Wege, zum Beispiel „Alle Fragen üben“ und „Anhören“. Etwa zwei Wochen vor dem Test kommt „Am Testtag: Was Sie brauchen“ dazu.

Üben

Tippen Sie unten auf „Üben“. Oben finden Sie:

  • „Alle Fragen üben“: alle Fragen der Reihe nach.
  • „Wiederholen“: die Fragen, die Sie heute noch einmal üben sollten. Die Zahl zeigt, wie viele. „Alles erledigt ✓“ heißt: Heute ist nichts fällig.
  • „Gemerkt“: Fragen, die Sie sich gemerkt haben.
  • „Anhören“: Das Handy liest Fragen und Antworten vor.

Themen

Darunter steht die Liste der Themen. Jedes Thema zeigt, wie weit Sie sind, zum Beispiel „5 von 12 geübt“. Nach 5 Antworten in einem Thema sehen Sie auch, wie viel richtig war, zum Beispiel „· 80 % richtig“. Ist ein Thema schwer für Sie, steht dort „Mehr üben“. Tippen Sie auf ein Thema, um es zu üben.

So funktioniert eine Frage

  1. Lesen Sie die Frage. Tippen Sie auf „Vorlesen“, wenn Sie sie hören möchten.
  2. Tippen Sie auf eine Antwort. Die App zeigt sofort „Richtig“ oder „Nicht ganz“ und die richtige Antwort.
  3. Tippen Sie auf „Nächste Frage“ oder wischen Sie weiter. Mit „Später wiederholen“ kommt die Frage wieder.

Falsche Fragen kommen später unter „Wiederholen“ wieder. Dort können Sie auf „Kann ich sicher“ tippen. Dann ist die Frage nicht mehr dabei.

  • Frage merken: Tippen Sie bei einer Frage auf 🔖. Sie finden sie dann unter „Gemerkt“.
  • Quelle: Jede Frage hat einen Link zur offiziellen Quelle beim BAMF.
  • Wörter mit ⓘ: Tippen Sie darauf. Dann sehen Sie, was sie bedeuten.

Fragen mit Bild

Einige Fragen haben im Test ein Bild.

  • Bei manchen Fragen beschreiben wir das Bild in Worten.
  • Manche Bilder haben wir selbst gezeichnet. Die Nummern sind wie in der offiziellen Liste vom BAMF.
  • Einige Bilder dürfen wir nicht zeigen. Über den Link „Quelle“ sehen Sie das Original beim BAMF. Diese Fragen kommen im Probetest nicht vor.

Anhören

Öffnen Sie „Anhören“ unter „Üben“. Das Handy liest eine Frage vor, wartet kurz zum Nachdenken und liest dann die Antwort. Das geht offline, ideal unterwegs. Wählen Sie ein Thema, „Zum Wiederholen“ oder „Alle Fragen“. Sie können auch das Tempo wählen.

Probetest

Tippen Sie unten auf „Probetest“ (das Stern-Symbol). Dann auf „Probetest starten“. Der Probetest ist wie der echte Test:

  • 33 Fragen, 60 Minuten. Oben sehen Sie die Zeit, die noch bleibt.
  • Bestanden ab 17 richtigen Antworten.
  • Sie sehen das Ergebnis erst am Ende.
  1. Tippen Sie auf eine Antwort. Dann tippen Sie auf „Antwort bestätigen“.
  2. Unsicher? Tippen Sie auf „Später beantworten“. Die Frage kommt am Ende wieder.
  3. Unter „Übersicht“ sehen Sie alle Fragen. Tippen Sie auf eine Frage, um sie zu beantworten oder zu ändern.
  4. Am Ende kommt „Antworten prüfen“. Erst mit „Probetest abgeben“ ist alles fertig.

Danach sehen Sie Ihr Ergebnis. Mit „Diese 3 wiederholen“ (die Zahl ändert sich) üben Sie Ihre Fehler.

Wenn Sie die App während des Tests schließen, können Sie später weitermachen: Tippen Sie auf „Probetest fortsetzen“. Wenn Sie auf „Verlassen“ tippen, zählen Ihre Antworten nicht.

Auf derselben Seite finden Sie auch „Am Testtag: Was Sie brauchen“. Dort steht, was Sie zum Test mitbringen.

Fortschritt

Tippen Sie unten auf „Fortschritt“. Sie sehen:

  • „Letzte 7 Tage“: wie viele Fragen Sie an jedem Tag geübt haben.
  • „Richtige Antworten, letzte 4 Wochen“: wie Sie Woche für Woche besser werden.
  • Abzeichen: kleine Belohnungen für Ihr Lernen. Bei einem offenen Abzeichen steht, wie Sie es bekommen.
  • „Letzte Probetests“: jeder Probetest mit ✓ oder ✗, Ihrem Ergebnis und dem Datum.

Lernplan und Erinnerung

Kennen Sie Ihren Testtermin? Dann plant die App für Sie.

  1. Tippen Sie auf der Startseite auf „Testtermin festlegen“. (Oder in den Einstellungen auf „Lern-Erinnerung“.)
  2. Geben Sie das Datum ein. Tippen Sie auf „Termin speichern“.
  3. Die App verteilt alle Fragen auf die Tage bis zum Test. Jeden Tag sehen Sie Ihr Ziel für heute.
  4. Tippen Sie auf „Täglich um 18:00 erinnern“. Ihr Handy fragt vielleicht, ob es Mitteilungen erlauben soll.

Der Termin bleibt auf Ihren Geräten. Ändern? Tippen Sie auf „Termin entfernen“ und geben Sie ein neues Datum ein.

Übersetzungen

Der Test ist auf Deutsch. Eine Übersetzung hilft aber, eine Frage zu verstehen. Übersetzungen sind kostenlos.

  1. Öffnen Sie die Einstellungen. Tippen Sie auf „Übersetzen in“. Wählen Sie Ihre Sprache. Sie können in der Liste suchen.
  2. Tippen Sie beim Üben auf den Übersetzen-Knopf bei der Frage. Er zeigt das Wort „Übersetzen“ in Ihrer Sprache.
  • Ein Computer auf Ihrem Handy übersetzt. Die Übersetzung kann Fehler haben. Kein Mensch hat sie geprüft.
  • Beim ersten Mal lädt das Handy vielleicht Ihre Sprache. Bei Android geht das nur mit WLAN, außer Sie schalten „Übersetzungen auch ohne WLAN laden (mobile Daten)“ ein.
  • Im Probetest gibt es keine Übersetzung, wie im echten Test.

Einstellungen

Tippen Sie auf der Startseite oben rechts auf das Zahnrad. Hier können Sie ändern:

  • Ihr Bundesland: „Ihr Bundesland“ oder „Bundesland: … (ändern)“.
  • „Lern-Erinnerung“: Testtermin und tägliche Erinnerung.
  • „Textgröße“: von 90 % bis 160 %. Ein Beispielsatz zeigt die Größe.
  • „Übersetzen in“: Ihre Sprache für Übersetzungen.
  • „Sicherung und Sync“: kostenlos. Ist die Sicherung Ihres Handys an, kommt Ihr Fortschritt in Ihre eigene iCloud oder Ihr Google-Konto. Wir sehen ihn nie.
  • „Auf ein anderes Handy übertragen“: Tippen Sie auf „Fortschritt senden“. So wird Ihr Fortschritt eine Datei. Auf dem neuen Handy tippen Sie auf „Fortschrittsdatei öffnen“. Das geht auch zwischen iPhone und Android.
  • „Darstellung“: „Wie das Handy“, „Hell“ oder „Dunkel“. Sie können auch „Ihre Farbe“ wählen.
  • „Vibration“: an oder aus.
  • „Hilfe & Anleitung“: öffnet diese Anleitung in der App, in Ihrer Sprache, wenn es sie gibt. Dafür brauchen Sie Internet.
  • „Feedback senden“: Schreiben Sie uns.

Vollversion: Was ist kostenlos?

Ohne Werbung und ohne Konto ist kostenlos:

  • alle Fragen mit Antwort und Quelle
  • Üben und Wiederholen ohne Grenze
  • Übersetzungen
  • die Sicherung Ihres Fortschritts
  • Probetests: heute unbegrenzt

Die Vollversion kommt bald. Sie ist ein Einmalkauf: kein Abo, nichts verlängert sich. Sie bietet unbegrenzt viele Probetests. Sobald man sie kaufen kann, sind 2 Probetests pro Woche kostenlos. Neue gibt es jeden Montag. Alles andere in der App bleibt kostenlos.

Später, wenn Sie die Vollversion gekauft haben, finden Sie sie oben in den Einstellungen. Wie Sie einen Kauf auf ein neues Handy holen, steht auf der Hilfe-Seite.

Tipps für ältere Lernende

  • Größere Schrift: Einstellungen, „Textgröße“. Probieren Sie 130 % oder 160 %.
  • Langsamer vorlesen: In „Anhören“ wählen Sie das Tempo „0.75×“.
  • Zuhören statt lesen: Tippen Sie bei einer Frage auf „Vorlesen“. Oder nutzen Sie „Anhören“ wie ein Radio.
  • Schwere Wörter: Tippen Sie auf Wörter mit ⓘ.
  • Kurz und oft: Jeden Tag ein paar Minuten reichen. Die tägliche Erinnerung hilft.
  • Keine Eile: Im Probetest können Sie Fragen mit „Später beantworten“ überspringen. Sie haben 60 Minuten Zeit.
  • Hilfe holen: Jemand aus der Familie oder ein Freund kann die App beim ersten Mal mit Ihnen einrichten.

Brauchen Sie Hilfe?

Antworten auf häufige Fragen finden Sie auf der Hilfe-Seite: Sicherung, Wiederherstellen, Übersetzungen und mehr.

Sie kommen nicht weiter? Schreiben Sie uns an support@citizenwise.app. In der App geht das auch: Einstellungen, „Hilfe & Anleitung“ oder „Feedback senden“.
